# CMO Weather Query

中央气象台天气信息查询工具。

## 使用场景

当用户需要以下信息时使用此 skill：
- 查询实时天气
- 获取天气预报
- 查看气象预警信息
- 查询城市天气信息
- 台风路径、雨雪实况等气象数据

## 使用方法

```bash
# 查询城市实时天气
node skill.js <城市名称>

# 查询天气预报
node skill.js <城市名称> --forecast

# 查看直辖市/省份下属所有区县与站点列表
node skill.js <直辖市/省份> --province

# 查询具体区县逐小时实况（含实时雨量）
node skill.js <区县名称> --hourly

# 查询天气预警
node skill.js --alert

# 更多功能
node skill.js --help
```

## 直辖市与下辖区查询建议

针对**北京、上海、天津、重庆**等直辖市：
- **必查下辖区**：直辖市跨度大且各区局部天气（如降雨、对流、温差）差异显著，市级总站数据可能存在更新延迟或无法完全代表各区实况。在查询直辖市天气时，强烈建议进一步查询其下属区县信息。
- **获取下辖区列表**：执行 `node skill.js <直辖市> --province` 查看包含的所有区县及站点（例如上海包含徐家汇、浦东、闵行、宝山、松江、青浦、嘉定等）。
- **细化核实实况**：根据用户具体所在区域或抽样多区，调用 `node skill.js <区县名称>` 或 `node skill.js <区县名称> --hourly` 获取更准确的降水与温湿度实况。

## 功能特性

- 支持全国城市天气查询
- 实时天气数据
- 天气预报
- 气象预警信息
- 台风、暴雨等特殊天气

## 数据来源

中央气象台官方数据接口
