# CLAUDE.md

本文件提供 AI 开发助手在处理此项目时的指引。

## 项目概述

Where Am I 是一个查询当前位置和本机公网 IP 地址的命令行工具。核心特点是**无需运行时依赖**，使用 Node.js 18+ 内置的 fetch API。

### 核心功能

- 查询公网 IP 地址
- 获取地理位置（省/市）
- 显示 ISP 运营商信息
- 多种输出格式（表格、JSON、简洁）

## 核心架构

### 主入口文件

`run.js` - 实现以下功能：
1. 解析命令行参数
2. 调用 cip.cc API 获取 IP 信息
3. 解析响应数据
4. 格式化输出

### 数据解析逻辑

cip.cc 返回的原始格式：
```
IP	: 203.0.113.1
地址	: 中国 上海 上海
运营商	: 电信
数据二	: 中国上海上海 | 电信
数据三	: 中国上海上海市 | 电信
URL	: http://www.cip.cc/203.0.113.1
```

解析使用正则表达式：`/^([^:]+?)\s*:\s*(.+)$/`

### 输出格式

1. **默认格式** - 带颜色的表格输出
2. **JSON 格式** - 便于程序解析
3. **简洁格式** - 仅输出 IP 地址
4. **原始格式** - 保留原始结构

## API 说明

### cip.cc API

- **端点**: `http://cip.cc`
- **方法**: GET
- **返回**: 纯文本格式
- **认证**: 不需要
- **限制**: 免费使用，建议勿频繁请求

### 响应字段

| 字段 | 说明 | 示例 |
|------|------|------|
| IP | 公网 IP 地址 | 203.0.113.1 |
| 地址 | 地理位置 | 中国 上海 上海 |
| 运营商 | ISP 信息 | 电信 |
| 数据二 | 备用数据源 | 中国上海上海 \| 电信 |
| 数据三 | 备用数据源 | 中国上海上海市 \| 电信 |
| URL | 查询 URL | http://www.cip.cc/203.0.113.1 |

## 常见问题处理

### Q: 如何添加更多 IP 信息源？

A: 在 `run.js` 中添加新的获取函数，类似于 `getIpInfo()`，然后合并结果。

### Q: 如何支持代理查询？

A: 可以使用环境变量 `HTTP_PROXY` 和 `HTTPS_PROXY`，Node.js fetch 会自动使用。

### Q: 如何添加缓存？

A: 可以在文件系统中创建 `.cache.json`，记录上次查询时间和结果，避免频繁请求。
